# AGENTS.md

Репозиторий находится в стадии проектирования методологии Fractal Agentic Software Engineering. Реализации ещё нет.

## С чего начать

Прочитай [brainstorming/README.md](brainstorming/README.md): там цель, рамка, словарь и правила ведения разговора. Затем [brainstorming/decisions.md](brainstorming/decisions.md) и [brainstorming/open-questions.md](brainstorming/open-questions.md).

## Правила работы с репозиторием

1. **Пока идёт проектирование, все записи идут только в `brainstorming/`.** Вне этой папки ничего не создаётся и не меняется без явной просьбы автора.
2. **Закрытый вопрос сохраняется сразу.** После каждого закрытого вопроса, подвопроса или обсуждения обнови файлы в `brainstorming/` и сделай коммит. Незаписанное решение теряется вместе с сессией.
3. **Коммит идёт прямо в `main` и сразу отправляется в `origin`.** Ветки и pull request на этой стадии не нужны.
4. **Один коммит на один закрытый вопрос.** В сообщении назови вопрос и суть решения.
